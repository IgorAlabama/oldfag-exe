# OLDfag.exe — версия 0.5 (560 вопросов)

Публичная ретровикторина с 5 уровнями и 9 вопросами в каждом раунде. Работает без сервера, подписок, ключей API и доступа к интернету.

## Проверка на компьютере

1. Распакуйте архив `OLDfag_GitHub_v0.5.zip` через «Извлечь всё».
2. Дважды откройте `index.html` в распакованной папке. Не открывайте из окна архива.
3. В папке должны лежать вместе `index.html`, `styles.css`, `questions.js`, `app.js`, а также подпапка `assets/` с тремя `.webp` картинками.

В качестве альтернативы используйте отдельный одиночный файл `OLDfag_GAME_v0.5.html`, где уже встроены изображения, скрипты и оформление.

## Публикация на GitHub Pages — без командной строки

1. Перейдите на https://github.com/new и авторизуйтесь. Впишите название репозитория, например `oldfag-exe`. Выберите **Public**, нажмите **Create repository**. Если не хотите создавать README на GitHub, оставьте его выключенным.
2. В распакованной папке выделите **содержимое**, а не саму папку: `index.html`, `styles.css`, `app.js`, `questions.js`, `README.md`, а также папку `assets` (с файлами WebP). Перетащите выделенное в пустой репозиторий или в **Add file → Upload files**. ZIP загружать не нужно.
3. Внизу страницы введите сообщение, например `Publish OLDfag.exe v0.5`, и нажмите кнопку сохранения (название интерфейса: **Commit changes** / **Propose changes**). Если интерфейс предлагает ветку, выберите прямое сохранение в основную ветку `main` в своём репозитории.
4. Откройте **Settings → Pages**. В блоке **Build and deployment** выберите **Source → Deploy from a branch**, ветку **main**, папку **/(root)**, нажмите **Save**.
5. Дождитесь публикации. На странице Pages появится адрес сайта, обычно `https://ВАШ_ЛОГИН.github.io/oldfag-exe/`. Откройте его и проверьте игру на телефоне.

Если сайт открылся, но без стилей и картинок, проверьте, что `index.html` в корне репозитория, рядом лежат оба `.js` и `.css`, а в `assets/` находятся именно три `.webp` файла.

## Пополнение вопросов

- В файле `questions.js` исходный список `rawQuestions`: одна строка — один вопрос. Формат:
  `[уровень, вопрос, ответ_1, ответ_2, ответ_3, ответ_4, индекс_правильного_от_0_до_3, пояснение]`.
- Добавляйте проверенные вопросы, не меняя `app.js`. Каждый будущий коммит автоматически обновит сайт через GitHub Pages.
- Первоначальные 60 вопросов сохранены, добавлено 500 новых (100 на уровень). Итого 560 / 112 на уровень.
- Общие рекорды игроков с разных устройств пока не собираются; личный рекорд хранится в браузере. Игра шуточная и не проверяет реальный возраст.

## Файлы для публикации

`index.html` — входная страница;
`styles.css` — стили и анимация;
`app.js` — логика игры;
`questions.js` — 560 вопросов;
`assets/club-start.webp`, `assets/club-success.webp`, `assets/club-denied.webp` — три варианта сцены.

*Примечание: данные вопросов автоматически проверены на структуру и дубликаты; при массовом расширении базы отдельные исторические факты и формулировки рекомендуется дополнительно вычитывать перед широкой публикацией.*
